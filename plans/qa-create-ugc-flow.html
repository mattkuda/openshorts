QA Runbook — Create UGC ads flow

Manual QA pass for the ReelFarm-style pipeline shipped 2026-07-03: hooks → avatars → demos → preview → sound → render → library. Mark each test Pass / Fail / Skip, then Copy results as Markdown at the bottom and paste it back to Claude to get fixes queued.

App: localhost:5175/#app Stack: docker compose up Free path: debug 🐛 → "Mock AI + mock videos" ON Real path: mockAI OFF (costs below)

TL;DR on cost. The Create UGC ads generation itself is $0 per video — FFmpeg runs locally, and avatars/hooks are reused assets. You only pay when creating new AI assets: ~4¢ per character portrait or look (Gemini), ~0.1¢ per hook batch. The only meaningfully-priced generation in the app is the AI Actor Ad (fal.ai talking head), ~$0.50–$1.50 per video. Your $10 fal balance ≈ 7–20 actor ads; everything in THIS runbook costs at most ~9¢ total on the real path, $0 on the mock path.

Setup (once, ~2 min)

S1Stack up & keys loaded
  1. Run docker compose up (backend :8000, frontend :5175). If backend code changed since last run: docker restart ai-shorts-backend.
  2. Open http://localhost:5175/?debug=true#app.
  3. Header should NOT warn about a Gemini key (comes from .env.local) — only Upload-Post may warn.

App loads on the Create tab, green ClipZoo theme, amber 🐛 button bottom-right.

S2Pick your cost mode
  1. Click 🐛 → toggle Mock AI + mock videos: ON for a $0 run, OFF to exercise real Gemini (~9¢ for this whole runbook).
  2. Confirm Brand Profile is set (Settings → Brand Profile → "Evex") — hooks and CTAs derive from it.

Toggle persists across reloads (localStorage).

A · Create UGC ads (the core flow)

A1Hooks auto-generate from the brand
  1. Create → Hook + Demo.
  2. Watch step "1. Hook" while it loads.

Within ~5s the carousel fills with 8 hooks about YOUR app (Evex/fitness), counter shows "1/8". Mock mode shows canned fitness hooks instantly.

A2Hook carousel + inline editing
  1. Click ‹ and › — counter cycles and wraps (8/8 → 1/8).
  2. Type into the hook card; flip away and back.

Preview text updates live as you type; your edit is remembered per-slot while cycling.

A3Avatar tabs: Default / My characters / Uploads
  1. Default: 4 photoreal thumbnails; first is pre-selected; click others.
  2. My characters: shows Runner Rachel's portrait + looks (and Mock Mia's placeholders).
  3. Uploads: upload a selfie clip, or debug "Mock clip".
  4. Click a selected thumb again to deselect.

Every selection instantly swaps the preview background; green ring marks selection; no broken-image icons.

A4Text position toggles (inside preview)
  1. Click the three small buttons at the bottom of the 9:16 preview.

Hook text jumps top / center / bottom; active toggle is white.

A5Demos step
  1. Click + and attach any screen-recording (or debug "Use mock demo").
  2. Click None to clear, re-attach.

Attached demo shows as a bordered thumbnail; None/thumbnail states are mutually exclusive.

A6Sound modal
  1. Click Sound → modal "Choose background music".
  2. Press ▶ on "sample ambient tone" — hear it; press again to stop.
  3. Uploaded Sounds tab → upload an .mp3 → appears in list.
  4. Select a track → modal closes, Sound button shows its name. Reopen → "No Sound" clears it.

Preview playback works; selection state highlighted; upload persists after reopening.

A7Generate — the money shot ($0)
  1. Hook picked + avatar selected + demo attached (or mock) + sound selected → Generate.
  2. Wait ~30–60s (Ken Burns render is the slow part).

Spinner overlays the preview → finished video plays in place: avatar push-in with outlined hook text at YOUR chosen position → your demo → music audible under everything. "Saved to your Library" appears.

A8My Videos + Library + persistence
  1. Scroll down — My Videos count incremented; new video playable.
  2. Library tab shows the same creation as a draft with a Schedule button.
  3. docker restart ai-shorts-backend, reload — everything still there.

Creations survive restarts (SQLite/Postgres), files under creations/.

B · Characters (the paid-asset flow, ~8¢ real)

B1Create a character (1 image = ~4¢ real / $0 mock)
  1. Characters → New Character → pick chips, add "extra details", name it → Generate portrait & save.

Real: photoreal 9:16 selfie-style portrait matching your attributes in ~10–20s. Mock: colored placeholder instantly.

B2Identity-consistent look (~4¢ real)
  1. Open the character → prompt bar → "Random" or type a scene → Generate.
  2. Compare the look against the portrait side by side.

Same face, hair, and vibe in the new scene (this is the whole feature — fail it if the person changes).

B3Character reuse everywhere
  1. Hook+Demo → My characters tab → new look appears.
  2. Create → Listicle → character circle picker → render → face on title + CTA slides.
  3. AI Actor Ads → step 2 → "My characters" strip present (don't run the paid generation).

One identity visible in all three surfaces.

C · Regression spot-checks

C1Slideshow still renders ($0)
  1. Create → Listicle → AI fill → Render.

5 slides + MP4; Evex is the green payoff slide; saved to Library.

C2Calendar + mock schedule
  1. Library → Schedule on any creation → pick platforms + future time (mockAI ON = no Upload-Post call) → Calendar tab.

Post appears on the right day; X cancels it (strikethrough).

C3Theme & nav sanity
  1. Skim every enabled tab; hover nav items; check disabled tabs show SOON and don't navigate.

Leaf-green accents only (no leftover neon mint/violet), readable text everywhere, no console errors (F12).
