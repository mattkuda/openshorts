Slideshow Automations v2

What SlideReels, ReelFarm, and the rest actually do; how our current build compares; and a requirements proposal with decisions for you to check off. Pick an option per block, add comments in any option's context or the notes box, then Copy decisions as Markdown and paste it back.

My recommendation in one paragraph. Go the ReelFarm direction, but cleaner: an automation has global slide instructions + a slide-count picker, and per-slide "overrides" are optional and sparse — you only write one when a specific slide needs it (e.g. "slide 4 soft-sells Evex"). Slide 1 is always the intro/hook (from the hook bank). Add the four controls you listed — CTA toggle with position, numbering toggle, text-length setting, and a third image source ("specific image") — and keep text AI-generated fresh on every run so no two posts are identical. That gets you SlideReels' sense of control with ReelFarm's automation, without ReelFarm's clutter.

The key ReelFarm detail (answers your main question)

In their editor the Content tab has a Slide count field (e.g. Static · 5) and a separate "Slide overrides — + Add" list that starts empty. You don't write instructions for every slide — the AI writes all 5 content slides from the automation's topic + tone + the chosen hook, and an override exists only where you added one (their example: Slide 4 — "this slide should subtly mention Cal AI as the solution to the problem — weave it in naturally as something that helped, not as an ad"). Same pattern for images: a default collection per slide role, plus optional "Image overrides" to pin slide 3 to one specific image. So the answer to "do I need to give each slide an override, or global instructions?" is: ReelFarm does global-by-default with optional per-slide pinning, and it's the right call — required per-slide directions (our current build) is busywork for a 6-slide show and makes changing the count awkward. Text is generated fresh per run (that's why their preview shows lorem text — real text doesn't exist until generation).

SlideReels' strength is you verify everything before it goes out. Where does that fit in an automation?
