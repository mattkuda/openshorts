# Competitor Analysis

Deep dives on the products in (or adjacent to) OpenShorts' space: AI UGC / short-form
video ad generators, plus the scheduling and editing tools we benchmark UX against.

Each file covers **what the product does** in depth, then leaves two sections for the
founder to fill in: **What I like** and **Out of scope**.

> Snapshot date: **June 2026.** Pricing and feature sets drift fast in this category —
> re-verify before quoting.

## Per-file template

Every competitor file follows the same shape so they're easy to scan side-by-side:

1. One-line positioning + a quick-facts table (site, category, pricing, best-known-for)
2. **What they do** — narrative overview
3. **Core workflow** — the actual click-path a user takes
4. **Key features**
5. **Output / content types**
6. **Strengths**
7. **Weaknesses & gaps**
8. **Relevant to OpenShorts** — concrete steal / avoid notes tied to our roadmap
9. **What I like** — _founder fills in_
10. **Out of scope** — _founder fills in_
11. **Sources**
