## Top 5 (web-verified — none collide with an existing similar tool)

1. **Viralform** (`viralform.com`/`.ai`) — does the most semantic work (viral + format + create); no known collision. **The standout.**
2. **Adforma** ⭐ (`adforma.com`/`.io`) — premium B2B; "ad" + "forma" (shape/form). Note: *Adform* (Danish ad-tech) exists but is distinct.
3. **Reelr** (`reelr.com`/`.ai`) — one word, vowel-dropped Flickr/Tumblr style; very recallable. `.com` may be squatted — verify.
4. **Adwave** (`adwave.com`/`.io`) — "ride the wave of AI ads." Run a USPTO check; possible adjacent "AdWave" mark.
5. **Virova** (`virova.com`/`.ai`) — invented "viral" + "nova"; `.com` held by an unrelated coffee brand, so lean `.ai`.

> The starred picks (ClipZoo, ReelBlast, ShortBlast, Reelborn, Clipnova, Adforma) have **not** all
> been availability-/collision-checked yet — only Adforma was verified above. Run a search + registrar
> check on the others before committing.
